# C# 6.0 大语言模型训练与推理教程 - 零第三方依赖

一套完全使用 C# 6.0 语法从零手写实现的大语言模型教学项目，不依赖任何第三方AI库，兼容 .NET Framework 4.6，Windows 系统即可运行，CPU 即可完成模型训练。

## 项目特色

- ✅ **严格C# 6.0语法**：不使用C#7+新特性（元组、模式匹配、本地函数等），兼容.NET Framework 4.6
- ✅ **零第三方依赖**：不需要任何NuGet包，不需要ML.NET、PyTorch、TensorFlow、Accord.NET等任何AI框架
- ✅ **完整Transformer架构从零实现**：
  - 矩阵运算基础库
  - Token Embedding + 可学习位置编码
  - GELU激活函数
  - LayerNorm层归一化
  - 因果多头自注意力机制（含因果Mask）
  - Transformer Block（Pre-LN + 残差连接 + 前馈网络）
  - 交叉熵损失函数
  - AdamW优化器
  - 自回归文本生成
- ✅ **内置数据集**：内嵌莎士比亚戏剧文本数据集（哈姆雷特独白、凯撒大帝演讲、理查三世独白），不需要下载任何外部数据文件
- ✅ **CPU即可训练**：迷你版模型约10万参数，CPU训练2-3分钟即可生成莎士比亚风格文本
- ✅ **HTML富文本教学界面**：左侧章节导航 + 右侧富文本文档，支持代码高亮、训练进度条、SVG损失曲线可视化，替代传统控制台黑框

## 模型配置说明

默认配置为迷你版CPU友好配置：
- 嵌入维度：64
- 注意力头数：4
- Transformer层数：2
- 最大序列长度：64
- Batch Size：8
- 训练步数：200
- 学习率：0.001
- 总参数量：约10万参数

如需更好的生成效果，可以修改`MainForm.cs`开头的常量，增大嵌入维度、层数、训练步数即可。

## 算法原理说明

### 自回归语言模型
模型训练目标是给定前面的字符，预测下一个字符的概率分布。训练完成后可以自回归生成文本：从起始提示词开始，每一步预测下一个字符，拼接到序列后继续预测，直到生成指定长度。

### 因果Mask
为了保证模型在预测第t个token时只能看到0~t位置的token，不能看到未来信息，在计算注意力分数时将j > i位置的分数设为负无穷，Softmax后权重为0，实现因果注意力。

### 训练流程
1. 从数据集中随机采样一个batch的输入和目标
2. 前向传播计算logits和损失
3. 反向传播计算所有参数梯度
4. 梯度下降更新参数
5. 重复以上步骤直到收敛
