# C# 人工智能高级编程

这是一套**严格遵循C# 2.0语法规范、完全零第三方库依赖**的人工智能教学源程序库，从基础矩阵运算、经典机器学习算法、全连接神经网络、卷积神经网络CNN到MNIST手写数字识别训练全套实现，纯原生手写实现，不依赖任何第三方AI库，单exe即可运行。

## ✨ 项目特色

- ✅ **严格C# 2.0语法**：不使用var、自动属性、lambda表达式、LINQ、扩展方法等任何C# 3.0及以上语法特性，兼容.NET Framework 2.0
- ✅ **零第三方依赖**：完全基于System/System.Drawing/System.Windows.Forms原生类库，不需要安装任何NuGet包，不需要Accord.NET、ML.NET、TensorFlow、PyTorch等任何AI框架
- ✅ **算法全手写实现**：矩阵运算、反向传播、卷积运算、池化、Softmax、交叉熵损失、Adam/梯度下降优化器全部从零手写实现
- ✅ **HTML富文本输出**：自研HtmlConsole控制台替代传统黑框Console，支持标题、代码高亮、运行结果块、提示框、SVG折线图、混淆矩阵、手写数字图片可视化输出
- ✅ **内置数据集支持**：MNIST数据集支持自动加载标准idx格式文件，无外部文件时自动程序生成内置模拟手写数字样本，无需下载即可完整运行所有演示
- ✅ **CPU即可训练**：所有模型都是轻量设计，普通CPU即可在1-2分钟内完成MNIST CNN训练，不需要GPU
- ✅ **WinForms桌面应用**：左侧树形导航 + 右侧HTML富文本展示，经典教学交互界面

## 🔧 CNN网络结构（手写数字识别）

```
输入: [1 x 28 x 28] 单通道灰度手写数字图
    ↓
Conv2D: 1→4 通道，卷积核3x3，Padding=1，Stride=1  → [4 x 28 x 28]
    ↓
ReLU激活函数
    ↓
MaxPool2D: 池化核2x2，Stride=2                   → [4 x 14 x 14]
    ↓
Flatten展平                                      → 784维向量
    ↓
Linear全连接层: 784 → 10类
    ↓
Softmax输出0-9每个数字的概率
```
总参数量约8000个，CPU训练3轮即可达到90%+准确率。

## 📊 MNIST数据集说明

本项目支持两种数据集模式：
1. **真实MNIST模式**：将以下4个官方MNIST idx格式文件放到exe同目录即可自动加载：
   - `train-images.idx3-ubyte`（训练集图片）
   - `train-labels.idx1-ubyte`（训练集标签）
   - `t10k-images.idx3-ubyte`（测试集图片）
   - `t10k-labels.idx1-ubyte`（测试集标签）
   
2. **内置样本模式**：如无上述外部文件，程序会自动使用内置算法生成0-9共10个数字的手写体原型样本，并添加随机噪声生成训练/测试集，无需下载任何文件即可完整运行所有演示。

## 📝 学习路线建议

1. 先看`Matrix.cs`和`MathUtils.cs`，理解基础矩阵运算
2. 从经典机器学习算法开始，逐个运行左侧章节演示理解原理
3. 学习MLP神经网络，理解前向传播和反向传播机制
4. 学习CNN卷积层、池化层实现，理解卷积运算原理
5. 运行MNIST训练演示，观察损失下降和准确率提升过程
6. 可以修改网络结构、学习率、训练轮数等超参数，观察效果变化

所有代码都有清晰的中文注释，适合C#开发者入门人工智能学习使用。
