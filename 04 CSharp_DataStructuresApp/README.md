严格遵循 **C# 2.0 语法规范**的数据结构桌面教学程序库。

## 项目特色

- **纯C# 2.0语法实现**：不使用任何C# 3.0及以上特性（无var、无LINQ、无lambda、无自动属性、无扩展方法），所有数据结构从零手写，不依赖.NET内置的List/Dictionary等高级集合类，完全适合学习底层原理
- **WinForms桌面应用**：基于.NET Framework 2.0，使用系统内置WebBrowser控件渲染HTML输出，无需额外依赖，兼容性好
- **HTML富文本替代Console**：自研`HtmlConsole`输出类，支持标题、代码高亮、运行结果块、提示/注意/成功/错误框、表格、分隔线等丰富格式，比传统黑框控制台直观清晰
- **经典教学界面**：左侧树形导航菜单 + 右侧富文本文档区域，点击即可切换章节学习

## 完整包含10个核心章节

| 章节   | 内容             | 核心知识点                                  |
| ---- | -------------- | -------------------------------------- |
| 第1章  | 顺序表 SeqList    | 动态数组、扩容机制、随机访问、插入删除、顺序表链表对比            |
| 第2章  | 单链表 LinkedList | 节点结构、头插尾插、插入删除、反转链表、链表遍历               |
| 第3章  | 栈 Stack        | 后进先出、入栈出栈、**括号匹配经典算法**、栈的应用场景          |
| 第4章  | 队列 Queue       | 先进先出、循环数组实现、入队出队、队列应用场景                |
| 第5章  | 二叉搜索树 BST      | BST性质、**先/中/后/层序四种遍历**、查找最值、树高度、树结构示意图 |
| 第6章  | 哈希表 Hashtable  | 哈希函数、链地址法解决冲突、负载因子自动扩容、学生成绩管理案例        |
| 第7章  | 排序算法           | 冒泡/选择/插入/快速排序、算法对比、**10000数据量性能实测**    |
| 第8章  | 查找算法           | 顺序查找、二分查找（循环+递归）、**100万元素性能对比实测**      |
| 第9章  | 字符串匹配 KMP      | 朴素匹配、next数组构造、KMP算法原理、经典字符串匹配          |
| 第10章 | 图 Graph        | 邻接表存储、广度优先搜索BFS、深度优先搜索DFS、图结构示意图、应用场景  |

每个章节都包含：**数据结构原理讲解** + **核心实现代码展示** + **可运行的实际操作演示** + **时间/空间复杂度分析** + **适用场景总结**，代码可直接运行调试。
