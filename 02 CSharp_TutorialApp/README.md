# C#入门教程的源程序库，C#2.0语法，桌面app型。

这是一套严格遵循 ‌C# 2.0 语法规范‌的桌面型入门教程源程序库。

## 项目特色

纯C# 2.0语法‌：严格禁用C# 3.0及以上特性，没有var类型推断、没有自动属性、没有lambda表达式、没有LINQ、没有扩展方法，全部采用C# 2.0原生语法（显式类型声明、手动属性get/set、匿名方法delegate(){}、泛型、可空类型、StringBuilder拼接）
WinForms桌面应用‌：基于.NET Framework 2.0，使用系统内置WebBrowser控件渲染HTML输出，无需额外安装WebView2或其他依赖
HTML替代Console‌：核心实现了HtmlConsole类，支持输出标题、代码块、深色运行结果、提示/注意/成功/错误提示框、表格、分隔线等富文本格式，完全替代传统控制台黑框
左侧导航+右侧内容‌：经典桌面教程界面，点击左侧章节树即可切换学习内容

## 完整包含10个章节

| 章节 | 内容 | C#2.0重点特性 | 
|------|------|------| 
| 第1章 | Hello World与基础语法 | 基本数据类型、显式类型声明、类型转换 | 
| 第2章 | 运算符与表达式 | 算术/比较/逻辑运算符、三元运算符 | 
| 第3章 | 条件判断与循环 | if/switch/for/while/do-while、break/continue | 
| 第4章 | 数组与字符串 | 一维/二维数组、string常用方法、StringBuilder高效拼接 | 
| 第5章 | 方法基础 | 值参数/ref引用参数/out输出参数、方法重载、递归 | 
| 第6章 | 面向对象基础 | 类与对象、手动属性封装、构造函数重载、静态成员 | 
| 第7章 | 泛型（核心特性） | ArrayList问题、List、Dictionary<K,V>、泛型方法 | 
| 第8章 | 可空类型与异常处理 | Nullable、??空合并运算符、try-catch-finally、TryParse、throw异常 | 
| 第9章 | 委托与匿名方法 | 委托定义绑定、匿名方法、闭包捕获变量、自定义排序 | 
| 第10章 | WinForms交互实战 | 控件事件绑定、模态对话框、实际交互演示 | 

每个章节都包含：‌知识点讲解‌ + ‌示例源代码展示‌ + ‌实际运行结果展示‌，方便初学者对照学习。
