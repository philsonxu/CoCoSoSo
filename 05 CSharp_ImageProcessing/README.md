# C# 图像处理教程源程序库

这是一套‌严格遵循C# 2.0语法、零第三方库依赖‌的桌面图像处理教程源程序库。

## 项目特色

‌纯原生零依赖‌：完全基于.NET Framework 2.0内置的System.Drawing GDI+，不需要安装任何NuGet包、不需要EmguCV/OpenCVSharp等任何图像处理库，单文件exe拷贝就能运行
‌严格C# 2.0语法‌：全程显式类型声明，不使用var、自动属性、lambda、LINQ、扩展方法等C#3+特性
‌算法从零手写实现‌：不调用任何系统内置滤镜，所有像素级算法全部自己LockBits+unsafe指针实现，非常适合学习底层原理
‌HTML富文本展示‌：自研HtmlConsole输出系统，处理前后图片直接嵌入HTML左右对比，附带代码高亮、原理讲解、性能测试数据
‌工业级高性能写法‌：教授LockBits内存直接操作技巧，比传统GetPixel/SetPixel快50~100倍

## 完整包含10个章节


|章节 | 核心内容 |
| ---- | -------------- |
|第1章 | GDI+基础与内置测试图生成（无需依赖外部图片文件） |
|第2章 | 灰度化算法：平均值法 vs 心理学加权法（0.299R+0.587G+0.114B）效果对比 |
|第3章 | 二值化与阈值分割：不同阈值（80/128/180）处理效果对比 |
|第4章 | 亮度与对比度调整：亮度偏移公式、对比度拉伸公式原理 |
|第5章 | 颜色特效：反色底片效果、怀旧棕褐色Sepia老照片滤镜 |
|第6章 | 图像滤镜：3×3均值模糊、经典浮雕效果（邻域差值+128） |
|第7章 | 几何变换：最近邻插值缩放、90度旋转、水平镜像翻转 |
|第8章 | 灰度直方图：直方图统计、直方图可视化绘制、亮暗图像直方图对比 |
|第9章 | ‌LockBits高性能像素操作‌：GetPixel vs unsafe指针性能实测对比，Stride对齐注意事项 |
|第10章 | 综合实战：GDI+画板（画笔/直线/矩形/椭圆/文字绘制演示） |

每章均包含：算法原理讲解 → 核心代码展示 → 原图/效果图左右直观对比 → 注意事项/性能总结。
