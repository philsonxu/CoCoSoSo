#### 线性结构
| 数据结构 | 实现方式 | 核心操作 | 时间复杂度 |
|---------|---------|---------|-----------|

| 链栈 | 链表 | Push/Pop/Peek | O(1)，无需预设容量 |

> - 前序遍历：根 → 左 → 右

| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ 稳定 |

#### 矩阵运算 Core/Matrix.cs

实现直接法和迭代法两类求解器：
- **列主元高斯消元法**：中小规模线性方程组首选，数值稳定
- **LU分解法**：PA=LU分解，支持重复使用分解结果求解多组右端项
- **雅可比迭代法**：简单迭代，适合大规模稀疏矩阵
- **高斯-赛德尔迭代法**：比雅可比收敛更快的迭代算法

#### 非线性方程求根 Algorithms/Calculus.cs
单变量非线性方程f(x)=0求根算法：
- **二分法**：最稳定，只要区间两端异号一定收敛，线性收敛
- **牛顿迭代法**：二次收敛，速度极快，需要提供导函数
- **割线法**：不需要求导，超线性收敛，用两点差商近似导数
- **不动点迭代法**：x=g(x)形式方程的经典迭代方法

#### 数值积分 Algorithms/Calculus.cs
定积分∫[a,b]f(x)dx数值近似算法：
- **梯形公式**：一阶代数精度，实现最简单
- **辛普森（抛物线）公式**：二阶代数精度，同等区间数精度远高于梯形法
- **自适应辛普森积分**：自动在函数陡峭处加密区间，达到指定精度自动停止
- **龙贝格积分**：理查德森外推加速，用较少的函数计算达到极高精度

#### 插值算法 Algorithms/InterpolationODE.cs
已知离散点构造插值函数：
- **拉格朗日插值**：经典多项式插值，适合节点较少场景
- **牛顿差商插值**：差商表构造，新增节点不需要重新计算全部基函数
- **分段线性插值**：不会出现龙格现象，简单稳定
- **三次样条插值**：三次多项式分段拼接，二阶连续可导，工程最常用（自然边界条件）

#### 常微分方程数值解 Algorithms/InterpolationODE.cs
求解初值问题dy/dx=f(x,y), y(x0)=y0：
- **欧拉法**：最简单的一阶方法，精度较低
- **改进欧拉法（Heun法）**：预测-校正格式，二阶精度
- **四阶龙格-库塔法RK4**：四阶精度，工业界最常用的ODE求解器，精度高稳定性好

#### 最小二乘拟合 Algorithms/LeastSquaresEigen.cs
数据拟合、线性回归核心算法：
- **一元线性拟合** y=ax+b，解析解公式直接计算
- **m次多项式拟合**，构造正规方程求解多项式系数
- **R²决定系数**计算，评估拟合优度
- 多项式求值工具函数

#### 特征值计算 Algorithms/LeastSquaresEigen.cs
矩阵特征值特征向量计算：
- **幂法**：求矩阵模最大的特征值和对应特征向量
- **反幂法**：结合矩阵求逆求模最小的特征值
- **雅可比方法**：对称矩阵全部特征值和特征向量的正交相似变换方法
