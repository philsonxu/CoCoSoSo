# C# 人工智能入门

这是一套‌严格遵循C# 2.0语法、零第三方库依赖‌的桌面型人工智能入门源程序库。

## 项目特色

‌纯原生零依赖‌：完全基于.NET Framework 2.0内置类库，10个经典AI算法全部从零手写实现，不需要安装任何NuGet包，不需要Math.NET/Accord.NET/ML.NET等任何AI第三方库，单文件exe拷贝即可运行
‌严格C# 2.0语法‌：全程不使用var、自动属性、lambda、LINQ、扩展方法等C# 3.0及以上特性，使用匿名方法delegate(){}、StringBuilder拼接、显式类型声明，兼容Windows XP+.NET 2.0运行环境
‌HTML富文本替代Console‌：自研HtmlConsole输出系统，支持标题层级、代码高亮、深色运行结果块、提示/注意/成功/错误提示框、数据表格、内嵌GDI+绘制的可视化图片，完全替代传统黑框控制台
‌全算法可视化‌：每个算法都配有原生GDI+绘制的效果演示图，拟合直线、Sigmoid概率曲线、分类散点图、聚类中心、函数曲线、蒙特卡洛投点图等全部直观可视化
‌经典教学界面‌：左侧树形章节导航 + 右侧HTML富文本文档区域，点击即可切换章节学习
